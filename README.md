# Matrix Decompositions

Deck 04 of the [Mathematics for Machine Learning &mdash; Companion Series](https://github.com/BrendanJamesLynskey/MML_Hub).

**Live presentation:** https://brendanjameslynskey.github.io/MML_04_Matrix_Decompositions/

Determinant &amp; trace, eigendecomposition, Cholesky, the singular value
decomposition, Eckart&ndash;Young low-rank approximation, the
matrix-decomposition taxonomy. Includes an interactive SVD compressor that
shows how few singular values you really need to recover an image.

## What's inside

- Determinant and trace &mdash; signed volume and the sum of eigenvalues
- Eigenvalues, eigenvectors and the characteristic polynomial
- The spectral theorem for symmetric matrices
- Cholesky factorisation $A = LL^\top$ for positive-definite $A$
- Singular value decomposition $A = U\Sigma V^\top$ &mdash; existence, uniqueness up to sign, geometric picture
- Eckart&ndash;Young: the best rank-$k$ approximation in Frobenius and operator norm
- Interactive SVD compressor on a 32&times;32 image
- The matrix-decomposition taxonomy (table 4.2 in the book)
